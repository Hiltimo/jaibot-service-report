# Jaibot Service Report V1.2

V1.2 gebruikt nu exact dezelfde rapportstructuur voor voorbeeld, PDF en Word.

PDF: opent een aparte rapportweergave met alleen het rapport en de foto's. Kies in het afdrukvenster 'Opslaan als PDF'.
Word: afbeeldingen hebben zowel CSS-limieten als een vaste Word-breedte van 480 px, zodat Word ze niet meer paginavullend importeert.

Foto's blijven vooraf gecomprimeerd voor snelheid en stabiliteit.
